# Workspace storage rule

- Do not create, download, cache, install, extract, train, or generate files on the C drive.
- Keep all task artifacts within `D:\Downloads\nodify-main` or another explicitly approved D-drive path.
- Put temporary files and tool caches under `D:\Downloads\nodify-main\.cache`.
- Before running tools that normally use a user-profile cache, redirect their cache and temporary environment variables to the workspace `.cache` directory.
- Do not move or copy project data to the C drive.
